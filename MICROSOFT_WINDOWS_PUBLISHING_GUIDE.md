## 🏬 Route 1: Publishing to the Microsoft Store (MSIX via PWABuilder)

This is the recommended route because Microsoft handles code signing and store hosting.

### 1. Register Your Microsoft Partner Center Account
1. Open the **Microsoft Partner Center Registration**:  
   👉 [https://partner.microsoft.com/dashboard/registration](https://partner.microsoft.com/dashboard/registration)
2. Sign in with your Microsoft Account (`osmansabor4444@gmail.com` or your preferred Outlook/Live account).
3. Select your account type:
   - **Individual Developer**: ~$19 USD one-time registration fee (no recurring fees).
   - **Company Account**: ~$99 USD one-time registration fee (if registering as a formal company/organization).
4. Complete credit card verification and email confirmation. Approval takes approximately 24 to 48 hours.

### 2. Reserve Your App Name & Locate Package Identity
1. In the **Microsoft Partner Center Dashboard** ([partner.microsoft.com](https://partner.microsoft.com)), click **Apps and games** (or **Windows & Xbox**).
2. Click **Create a new product** > **MSIX or PWA app**.
3. Type: `ISO System (IMS)`
4. Click **Check availability** and then click **Reserve product name**.
5. Once reserved, navigate down the left menu:
   - Click **Product management**

## 💻 Route 2: Building Standalone `.exe` & `.msi` Installers Directly

If you want a native desktop executable installer to give directly to clients or install on internal PCs:

### Option A: Local Build on Your Windows PC
1. Download or clone this repository to your Windows PC.
2. Ensure [Node.js](https://nodejs.org) and [Rust](https://rustup.rs) are installed.
3. Run the automated script included in this repository:
   ```cmd
   build-windows.bat
   ```
   Or run the commands manually:
   ```cmd
   npm install
   npm run build
   cargo tauri build --bundles nsis,msi
   ```
4. Output installers will be created in:
   - `src-tauri/target/release/bundle/nsis/ISO-System-IMS_1.0.0_x64-setup.exe`
   - `src-tauri/target/release/bundle/msi/ISO-System-IMS_1.0.0_x64.msi`

### Option B: Automated Cloud Build via GitHub Actions (Zero Local Setup)
You can compile native `.exe` installers in the cloud without installing any tools on your PC:
1. Push this project to your GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "Initial release of ISO System (IMS) by Osman Khrif"
   git branch -M main
   git remote add origin https://github.com/YOUR_GITHUB_USERNAME/iso-system-ims.git
   git push -u origin main
   ```
2. The workflow file `.github/workflows/build-desktop.yml` will automatically build the Windows `.exe` and `.msi`.
3. Go to your GitHub repository > **Actions** tab.
4. Click on the completed workflow run and download the **`Windows-x64-Installer-EXE`** zip!

## 🛡️ SmartScreen & Direct Distribution Tip

When users download a newly created standalone `.exe` directly from the internet, Windows Defender SmartScreen may display:
*"Windows protected your PC — Unknown publisher"*

**Two Best Solutions:**
1. **Publish via Microsoft Store (Route 1)**: Microsoft Store packages are verified by Microsoft's cloud certificate, so users never see SmartScreen warnings.
2. **Sign the `.exe` with Azure Trusted Signing**: Microsoft offers *Azure Trusted Signing* (approx. $10/mo) for individual developers to sign `.exe` binaries with high reputation.
