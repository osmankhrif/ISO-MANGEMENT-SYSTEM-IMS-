Privacy Policy

Application: ISO Management System (IMS) • Publisher: Osman Khrif • Effective Date: October 2, 2026
🛡️ Core Privacy Guarantee

ISO Management System (IMS) is designed with an offline-first, zero-telemetry architecture. All audit records, nonconformance reports, schedules, auditor certifications, and ISO compliance data are stored locally on your device within your secure local SQLite database or browser storage sandbox. We do not transmit, collect, sell, or monetize your industrial or personal data.

1. Information We Do Not Collect

Because ISO Management System (IMS) functions as a client-side industrial compliance solution:

  • No Personal Tracking: We do not track user behavior, screen usage, mouse movements, or keystrokes.
  • No Third-Party Ad Networks: The application does not integrate advertising SDKs, tracking pixels, or marketing trackers.
  • No Proprietary Data Ingestion: Audit evidence, checklists, findings, and plant photographs created in the application remain under your sole custody.

2. Information Stored Locally On Your Device

To perform audit management functions, the application stores data locally on your device:

  • Local Database: SQLite database schema containing audit programs, clauses, checklist questions, lead auditor assignments, and corrective actions.
  • User Preferences: Display themes, column layouts, and user simulated roles saved in your browser or desktop storage.
  • File Exports: When you initiate an export (Excel sheets, PDF summaries, JSON backup archives, or iCalendar feeds), the files are generated client-side and saved directly to your local file system.

3. Device Permissions & File Access

The application requests only permissions strictly necessary for its functionality:

  • Storage / File System: Used exclusively when you explicitly choose to import an audit template or save an exported report or backup archive.
  • Network Connectivity: Only utilized to fetch public web fonts or load web assets. No local audit database content is uploaded to any remote server during standard operations.

4. Data Retention and Deletion

You have complete control over your data at all times:

  • You can export full system backups as encrypted/unencrypted JSON archives at any time via the Backup & Restore hub.
  • You can reset or wipe all stored local audit records instantly using the Factory Reset Database option in Settings.
  • Uninstalling the desktop application or clearing browser storage permanently erases all locally cached application records from the host device.

5. Compliance with Global Privacy Regulations

This privacy policy conforms to the requirements of the General Data Protection Regulation (GDPR), the California Consumer Privacy Act (CCPA), and Microsoft Store Developer Certification Policies.
